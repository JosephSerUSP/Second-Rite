# Review scope

This branch is intentionally stacked on `agent/swept-item-cohort` / PR #578.

It does not replace any canonical item model. It pins the C and Blender-native source refs, measures their already-authored products, and preserves controlled in-engine evidence for the three identities both lanes independently attempted: Cerberus Fang, Mimic Tongue, and Phoenix Pinion.

The first run found that the pinned Blender-native Mimic Tongue and Phoenix Pinion contain degenerate faces rejected by the real runtime. Those contact-sheet cells are fallback geometry and are explicitly excluded from artistic comparison. Cerberus Fang remains the valid direct visual A/B. See `FINDINGS.md` and `runtime-compatibility.txt`.
