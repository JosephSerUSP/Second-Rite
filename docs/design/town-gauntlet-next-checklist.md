# Next sterile town gauntlet checklist

Use this checklist before starting the next town visual run.

- [ ] Base is current `main` plus only explicitly named generic non-visual tooling.
- [ ] Agent has not been given links to old town visual PRs/branches.
- [ ] Agent has not opened old town contact sheets, reports, `.blend`s, packages or town-specific builders.
- [ ] `docs/design/town-authoring-known-good.md` is the only historical visual-research summary supplied.
- [ ] `walker.png` is the only pre-existing repository visual asset available to the task.
- [ ] Camera/billboard infrastructure is supplied as known-good tooling rather than reimplemented by the art agent.
- [ ] Each independent architectural direction starts empty.
- [ ] Iteration within one direction is allowed and encouraged.
- [ ] Clay/native architectural read is reviewed before expensive material polish.
- [ ] Basic presentation acceptance checks happen before aesthetic scoring.
- [ ] Final winner remains real coarse 3D geometry plus one baked beauty atlas; no camera-space background-plane substitution.
- [ ] Winner exports collision/bounds and spatial anchors suitable for later insertion into the already-proven bounded-lane playability seam.
