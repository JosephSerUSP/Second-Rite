# Metro train models

These OBJ/MTL files are deterministic runtime products generated from `tools/generate_metro_train_models.py`. Geometry and palettes are original repository-authored data; no third-party meshes or textures are used.

Regenerate: `python tools/generate_metro_train_models.py`

Verify: `python tools/generate_metro_train_models.py --check`

The mover runtime does not know these filenames; maps select state models through authored mover data.
