# Recorded study scripts

These are copies of the once-only authoring scaffold, read-only source/surface/
region inspections and direct saved-source refinement used in this review.
They are evidence, not supported production entry points. Recorded paths refer
to this task's ignored `out/work/` files. Retained JSON/images in the parent
folder supply those inputs for inspection; do not blindly execute the scripts.

**All six sources exist now. Never rerun `author_scaffold.py` to regenerate
them.** The saved `.blend` documents are authoritative. The refinement also
already ran and has guarded backups; do not repeat its depth scaling or surgery.
Inspect and edit the saved source for future improvements, then run the normal
read-only compiler and actual item viewer. Reusable mesh/material primitives
remain `item_kit`, `path_sweep` and `surface_atlas` under `tools/blender`.
