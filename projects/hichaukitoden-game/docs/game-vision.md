# Game vision

## Identity

**Second Gate** is a dark, PSX-influenced, foreboding monster-collecting dungeon crawler.

This note is the high-level home for the game's identity and intended player experience. It should remain comparatively stable and concise; detailed systems, places, creatures, scenes, and production decisions should live in their own notes and link back here where useful.

## Documentation role

This document records design intent. It does not assert that any particular mechanic, asset, scene, or piece of content is implemented. Concrete authored state lives in the Project's `data/` and `assets/`.

As the legacy design corpus is audited, keep only the enduring principles here rather than turning this page into a backlog or implementation ledger.
