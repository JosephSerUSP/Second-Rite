# Strata and return

## St. Maria and the Labyrinth

Second Gate alternates between an authored surface place and increasingly strange descent. **St. Maria** should remain materially present in the player's memory: rooms, people, services, objects, and changed states give expeditions a social and emotional outside.

The Labyrinth is not simply a sequence of combat floors. Each stratum should establish a distinct spatial/material identity, create reasons to remember routes and discoveries, and contribute to a larger pattern that becomes harder to explain as the player descends.

## Return is part of the dungeon

The route home is not downtime after the “real” dungeon. A good expedition asks the player to evaluate what remains between the current position and safety, what has already been committed, and what would be lost by pushing farther.

Returns should create authored consequences in St. Maria where appropriate. Repetition is valuable when a revisited place has acquired new practical or emotional meaning rather than merely respawning the same content.

## Revisit spiral

The intended progression can revisit earlier strata from a changed position: new routes, new capabilities, altered risks, remembered landmarks, optional discoveries, or narrative reinterpretation can make old space newly meaningful.

Revisiting should therefore feel like a **spiral**, not a reset. The player returns to something recognizable while carrying changed knowledge, party composition, resources, and world context.

The detailed historical `stratum-revisit-spiral.md` remains available in the [legacy archive](../archive/legacy-repo-design/README.md). Current owner review of that structure is tracked in [#677](https://github.com/JosephSerUSP/Second-Rite/issues/677); do not turn an unresolved proposal into a fixed floor schedule here.

## São Paulo Metro stratum

A São Paulo Metro stratum is a durable example of the game's deeper-world direction: an environment recognizably drawn from lived modern infrastructure can appear inside the Labyrinth without first being translated into conventional fantasy symbolism.

Its strength comes from recognition colliding with impossibility. It should not be explained away immediately as a themed dungeon. Its existence should contribute to the sense that the Labyrinth contains histories/memories that do not fit a single ordinary chronology.

The Metro is normally a **protected discovery**. It can be shown publicly if there is a deliberate reason, but it should not become default store/trailer imagery merely because it is visually striking.

## Scale

Floor/stratum count is a production and content-density decision, not an identity claim. Prefer fewer memorable strata to filler geography. Historical plans that name exact floor counts are provenance, not current authority.
