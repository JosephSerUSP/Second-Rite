# Historical one-shot item builders

These four scripts are preserved from assessment parent
`205f99fb26822e289342b69d8c68875aceb6c869`. They are evidence, not executable
entry points. Their imports and old installation-relative paths are frozen.

Retargeting them to the live Project would let old recipes overwrite products
whose Blender documents now own the source. Use the item source compiler or
the supported staged production adapters in `tools/blender/README.md` instead.
No item document or runtime model was removed or regenerated by this archival.
