# Commercial Release Pipeline

This folder turns Second Gate's commercial identity into work that can be
planned, tested, shipped, and carried into a broader Gate catalog. It is
intentionally separate from engine specifications and detailed authored-content
design.

- [`release-plan.md`](release-plan.md): evidence gates, February 2027 Next Fest
  target, Steam-page timing, launch/support sequence, and catalog handoff.
- [`proof-build.md`](proof-build.md): the smallest St. Maria → Labyrinth → return
  slice that can prove the game's emotional and commercial loop.
- [`store-positioning.md`](store-positioning.md): current public-facing pitch,
  trailer/capsule rules, tag direction, content pillars, and protected spoilers.
- [`gates-franchise-strategy.md`](gates-franchise-strategy.md): working $9.99
  paid-game hypothesis, compact serial Gate strategy, optional soundtrack/art
  products, sequel-page timing, and corpus recurrence.

The governing product direction lives in
[`../design/commercial-identity.md`](../design/commercial-identity.md).

Detailed game-content concepts remain outside this folder. In particular, the
planned São Paulo Metro dungeon stratum is documented in
[`../game design/sao-paulo-metro-stratum.md`](../game%20design/sao-paulo-metro-stratum.md)
because it is authored Second Gate content, not a marketing invention.
