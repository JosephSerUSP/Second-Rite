# Game decisions

This folder records durable **Second Gate game-design decisions** whose rationale should survive individual chats, branches, and implementations.

A decision note should answer:

- What did we decide?
- What context or alternatives mattered?
- Why was this choice made?
- What consequences follow from it?
- Under what conditions should it be reconsidered?

Do not use this folder for Thestra architectural decisions, CI/process rules, or commercial/business decisions. Those have different authorities.

Start from [`../templates/decision.md`](../templates/decision.md) when useful.
