# P003 The Locksmith

A tiny mostly-noncombat Project involving inventory, dialogue conditions, locks, persistent world changes, branching progression, and at least two endings.

## Walkthrough

1. Check the chest to find the Rusty Key.
2. Talk to the NPC and choose "Yes" to receive the Master Key.
3. Interact with the door. If you have the Master Key, you get the Secret Ending. If you only have the Rusty Key, you get the Normal Ending.
