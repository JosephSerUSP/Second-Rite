# Meshy old stone village square

The Second Gate experimental town uses the owner-supplied archive
`Meshy_AI_Old_Stone_Village_Squ_0821061722_texture_obj.zip` as its environment
source. The archive contains one textured OBJ, one MTL, and one PNG; it did not
contain gameplay anchors, collision, lighting, or event semantics.

The source is retained outside the repository because it was supplied as a
local download. The promoted Project asset is generated by
`tools/asset-production/build_meshy_town_package.py`. That step keeps the
source texture, uses the quality-preserving reduction path for this collection
of disconnected architectural pieces, rotates the source square 270 degrees
around the town-center anchor so the church-facing side is presented to the
player, and writes an explicit floor envelope. The map's bounded-lane provider
remains the movement authority until the full walkable-environment collision
seam is promoted.

The church square is authored in `data/maps/16.json`: the central doorway at
the package's `[8.0, 5.5, -1.5]` town-center anchor is
the Labyrinth of Thestra entrance, while the bell, guard, merchant, and citizen
are ordinary map events. The town uses `town_default`'s sky panorama and an
inline high-minimum-factor fog profile so the supplied village texture remains
readable.

## Blender calibration handoff

`assets/authoring/town/second_gate_town_annotation.blend` is an editable scene
generated from the supplied OBJ. It contains the full source mesh, a
viewport-only `PLAYER_REFERENCE`, the `WALKER_SPRITE` using the game's actual
walker sheet, a `WALKABLE_MAIN` full-grid tracing template, and named markers:
`SPAWN_PLAYER`, `CHURCH_CENTER`, `CHURCH_ENTRANCE`, and
`ORIENTATION_FORWARD`. The supplied church reference image is packed into the
scene as `REFERENCE_TARGET_PHOTO` and used as a camera comparison overlay.

The owner should edit `WALKABLE_MAIN` to remove blocked cells, resize or move
the player proxy if necessary, and reposition the named markers. Return the
edited `.blend`; its annotations are the intended authority for the next
walkable-environment pass.

The current calibration lowers the source environment by 0.1 Blender units
relative to the player and uses a half-size walker/player reference. Runtime
lane camera tracking eases toward its projection-window target, with the
interpolation speed authored in `data/maps/16.json`. The scene can be
regenerated with Blender 5.x using
`tools/asset-production/create_meshy_annotation_scene.py`.

Regeneration, after supplying the source archive's extracted OBJ and PNG:

```text
python tools/asset-production/build_meshy_town_package.py \
  --source <source>/Meshy_AI_Old_Stone_Village_Squ_0821061722_texture.obj \
  --texture <source>/Meshy_AI_Old_Stone_Village_Squ_0821061722_texture.png \
  --output projects/hichaukitoden-game/assets/environments/town_church
```

No embedded document in the archive was treated as repository or gameplay
authority; the user's request and the repository's data-driven contracts are.
