# Creatures

Creature notes belong here when they carry durable **Second Gate design meaning** beyond what is already represented by authored data.

Use a creature note for things such as:

- concept and identity;
- combat role and intended feel;
- visual direction;
- narrative or ontological associations;
- relationships to places, systems, or other creatures;
- rationale that would otherwise be lost when looking only at JSON data.

Do not manually duplicate implemented numeric data just to make a prettier catalogue. Link or refer to the authoritative Project data when exact implemented values matter.

Start new notes from [`../templates/creature.md`](../templates/creature.md) when the template is useful; it is a convenience, not a required schema.
